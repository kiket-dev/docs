Kiket integrations are **evidence adapters** — they normalize external events into the platform raw inbox and evidence graph.

## Shipped adapters

| Connector | Role | Ingress |
| --------- | ---- | ------- |
| GitHub | Change evidence + Issues source-of-work | `/integrations/github/webhook` |
| Slack | Approval and discussion evidence | `/integrations/slack/webhook` |
| Generic webhook | User-defined JSON mapping | `/integrations/webhook` |

## Getting started

1. Install adapter metadata with `POST /platform/extensions` (owner/admin).
2. Register an event source with `POST /platform/event-sources`.
3. Store webhook secrets with `POST /platform/credentials` when needed.
4. Point the external system at the ingress URL with tenant/source headers.
