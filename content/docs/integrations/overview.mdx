Kiket integrations are **evidence adapters** — they normalize external events into the platform raw inbox and evidence graph.

## Shipped adapters

| Connector | Role | Ingress |
| --------- | ---- | ------- |
| GitHub | Change evidence + repository signals | `POST /integrations/github/webhook` |
| Slack | Approval and discussion evidence | `POST /integrations/slack/webhook` |
| Generic webhook | User-defined JSON mapping | `POST /integrations/webhook` |
| Jira | Work-item lifecycle and comment evidence | `POST /integrations/jira/webhook` |
| ServiceNow | ITSM record and comment evidence | `POST /integrations/servicenow/webhook` |

Legacy 1.x placeholder extension repos (email, Teams, calendar/OAuth helpers, etc.) were removed. New connectors ship via [`kiket extension publish`](/docs/api/extensions) and install from Settings → Extensions.

## Getting started

1. Install adapter metadata with `POST /platform/extensions` (owner/admin) or **Install in app** from the [marketplace](https://kiket.dev/marketplace).
2. Register an event source with `POST /platform/event-sources`.
3. Store webhook secrets with `POST /platform/credentials` when needed.
4. Point the external system at the ingress URL with tenant/source headers.
