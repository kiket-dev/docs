**Start here:** [Build your first evidence adapter](/docs/integrations/first-evidence-adapter).

Evidence adapters normalize external systems into Kiket's **raw inbox** and **evidence graph**. They use scoped API keys and `/platform/*` routes — not the removed legacy `/extensions` webhook catalog.

## Platform surfaces

| Surface | Purpose |
| ------- | ------- |
| `POST /platform/raw-events` | Idempotent raw inbox ingest |
| `POST /platform/evidence` | Normalized evidence records |
| `POST /platform/extensions` | Install adapter metadata (owner/admin) |
| `POST /platform/event-sources` | Bind ingress (webhook URL, source key) |
| `POST /platform/credentials` | Sealed secrets (owner/admin) |
| `GET /platform/extension-ingestion/contract` | Machine-readable adapter contract |

## Authoring tools

- **`kiket extension init`** — scaffold `kiket-extension.yaml` + starter adapter
- **`kiket extension validate`** — validate manifest locally
- **`kiket extension test`** — POST a fixture raw event using API-key auth
- **`@kiket-dev/sdk`** — manifest Zod schema + `createIngestionClient()`

## Legacy note

Older docs described outbound Kiket→extension webhooks with issue/comment scopes. That model is retired. New connectors are **ingress adapters** that call the platform API using the Kiket SDK.
